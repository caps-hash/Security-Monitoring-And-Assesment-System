# SAMS admin guide

## Accounts

Create the first HR user in Supabase Authentication, then promote that profile from the SQL Editor:

```sql
update public.profiles
set role = 'hr'
where email = 'hr@example.com';
```

After that, HR creates employee and supervisor accounts in Personnel. The application does not expose a role-change form. Employee numbers are generated by the server.

Deactivate an account from Personnel when access must stop. Reactivate it the same way. Do not delete an authentication user unless the related profile and records have been reviewed.

## Assignments

Save the post, duty location, and shift before assigning an employee. An assignment needs an employee, supervisor, post, location, shift, and start date. A supervisor's pages follow that assignment.

## Database

Apply `supabase/schema.sql` to a new project. For an existing project, apply any missing files in `supabase/migrations/` in date order. Do not reset the database to add a later phase. The Phase 9 audit migration creates no rows, so "Success. No rows returned" is expected.

Required later migrations include:

- `20261108_phase7_sms_notifications.sql`
- `20261109_phase8_ranking_settings.sql`
- `20261110_phase9_audit_logs.sql`

## SMS

Set either Twilio (`TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_FROM`) or Semaphore (`SEMAPHORE_API_KEY`, optional `SEMAPHORE_SENDER`). Set `SMS_WEBHOOK_SECRET` before accepting provider callbacks. Set `SMS_CRON_SECRET` or `CRON_SECRET` for `/api/sms/reminders`. A missing provider is logged as not configured and does not undo the assessment action.

## Storage

The private buckets are `attendance-evidence` and `evaluation-documents`. Attendance photos are signed only for an authorized attendance record and only for that employee's evidence path. Employees cannot download evaluation files. Downloads for HR and the assigned supervisor use a short-lived signed URL.

## Audit and security

HR reads `/dashboard/hr/audit`. Audit writes use the service role and omit passwords, tokens, photo paths, and coordinates. A failed audit insert does not roll back the original action.

Keep `SUPABASE_SERVICE_ROLE_KEY`, SMS credentials, email credentials, and webhook secrets out of `NEXT_PUBLIC_` variables and out of the browser. Do not disable Row Level Security to make a page load.
